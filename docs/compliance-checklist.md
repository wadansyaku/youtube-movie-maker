# YouTube収益化 コンプライアンスチェックリスト

> AI生成コンテンツのYouTube投稿における品質・オリジナリティ・法的適合性の確認

---

## 📋 必須チェック項目

### 1. オリジナリティ担保

| チェック | 項目 | 説明 |
|:---:|------|------|
| ☐ | **Decision Log完成** | 編集意図(50字以上)、人間の貢献(100字以上)を記録 |
| ☐ | **創造的編集の実施** | AI出力をそのまま使用せず、人間が編集・選択・構成 |
| ☐ | **独自の構成・ストーリー** | 単なるAI出力の羅列ではなく、意図のある構成 |
| ☐ | **差別化ポイント明確** | 他のAI生成コンテンツとの違いを説明可能 |

### 2. 著作権・知的財産

| チェック | 項目 | 説明 |
|:---:|------|------|
| ☐ | **全素材がオリジナル** | AI生成または自作素材のみ使用 |
| ☐ | **商用利用可能なツール** | Suno Premium、Runway Unlimited等で生成 |
| ☐ | **実在人物不使用** | AI生成に実在人物の肖像を使用していない |
| ☐ | **商標・ブランド不使用** | ロゴ、ブランド名等を含まない |
| ☐ | **著作権素材不使用** | 映画、音楽、画像等の著作物を参照していない |

### 3. AI使用の開示

| チェック | 項目 | 説明 |
|:---:|------|------|
| ☐ | **Studio設定の確認** | YouTube Studioで「改変または合成されたコンテンツ」を適切に開示 |
| ☐ | **説明欄への記載** | AI生成ツール使用について説明欄で言及 |
| ☐ | **生成メタデータ記録** | 使用したAIツール、プロンプト、設定を記録保存 |

### 4. コンテンツポリシー

| チェック | 項目 | 説明 |
|:---:|------|------|
| ☐ | **コミュニティガイドライン準拠** | 暴力、ヘイト、有害コンテンツを含まない |
| ☐ | **誤情報を含まない** | 事実として誤解される可能性のある内容を検証 |
| ☐ | **広告主フレンドリー** | 収益化に適したコンテンツ |

---

## 🔍 エクスポート前の最終確認

```
□ Decision Log の編集意図が明確に記載されている
□ 人間の貢献が具体的に記録されている
□ 全素材のメタデータ（ソース、生成パラメータ）が記録されている
□ World Bibleに沿った一貫性が維持されている
□ サムネイルがオリジナルで作成されている
□ タイトル・説明・タグが適切に設定されている
```

## 📝 推奨する説明欄テンプレート

```
【このチャンネルについて】
本チャンネルでは、AI映像生成ツール（Runway）およびAI音楽生成ツール（Suno）を
補助的に活用しながら、人間が企画・構成・編集を行いオリジナルコンテンツを制作しています。

【AI使用について】
- 映像: Runway Gen-3を使用し、人間が選別・編集
- 音楽: Suno Premiumで生成、人間が選曲・編集
- すべてのAI出力は人間がレビュー・修正を行っています

【World Bible】
シリーズ全体で一貫した世界観を維持するため、
独自のスタイルガイド（World Bible）に基づいて制作しています。
```

## ⚠️ 注意事項

1. **YouTubeポリシーは変更される可能性があります** - 定期的に最新のガイドラインを確認してください
2. **完全な収益化保証はありません** - チェックリストの完了は収益化を保証するものではありません
3. **記録の保持** - Decision Log、生成メタデータは長期保存を推奨します
