# Archive

このディレクトリは、旧サブアプリや実験的実装の保管庫です。
メインの実装はルートの `src/` と `video_editor/` を参照してください。

## 内容

- `archive/apps/video-automation`: 旧 Remotion ベースのアプリ
- `archive/apps/production-os`: 旧 Production OS (MVP)
- `archive/production-os`: 旧 Production OS の一部（参照用）

## 方針

- `archive/` 配下は基本的にメンテ対象外
- 調査や移植が必要なときのみ参照
